# Jobs Child Theme
Child of Twenty Twenty-One. Adds a "Jobs" CPT (Job Title, Salary, Location) with no plugins.

## Setup
1. Install & keep the parent theme **Twenty Twenty-One**.
2. Copy `jobs-child/` to `wp-content/themes/` and activate it.
3. Settings > Permalinks > Save (if /jobs/ 404s).
4. Add jobs under Jobs > Add New. Archive: /jobs/
